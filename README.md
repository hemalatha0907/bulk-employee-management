# Bulk Employee Management System

A MERN stack project that accepts many employee records at once, removes duplicates, sorts them, and saves them to MongoDB.

## What it does
- Accepts a list of employees in one request
- Removes duplicate employees using Employee ID
- Sorts employees by ID and name
- Saves the final list to MongoDB

## Technologies used
- React.js
- Node.js and Express.js
- MongoDB
- Postman (for testing)

## How to run
1. Clone the project: `git clone https://github.com/hemalatha0907/bulk-employee-management.git`
2. Open the backend folder and run: `npm install`
3. Create a `.env` file with your MongoDB connection string
4. Start the server: `npm start`
